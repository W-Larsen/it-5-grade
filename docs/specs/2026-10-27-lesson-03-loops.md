# Spec: урок 3 «Біт у циклі» — цикли в грі + лічильник команд

**Дата:** 2026-10-27 · **Статус:** реалізовано; теорія для вчителя (`Урок-3-теорія-для-вчителя.docx`) готова

Друге заняття блоку «Біт усередині комп'ютера». Попередній spec: [урок 2](2026-10-20-lesson-02-bit-processor.md).

## Розуміння (підтверджено)

- **Що робимо:** заняття 3 — сайт-презентація на каркасі `shared/deck/`, рівні гри «Біт-програміст» у слайдах, конспект для вчителя. Теорію для вчителя (.docx) робимо останньою.
- **Навіщо:** рівні уроку 2 учневі були легкі. Додаємо перше нове поняття програмування — **цикл** — і поглиблюємо тему процесора.
- **Теорія:** «Пам'ять тісна» пояснює, *навіщо* потрібен цикл (кожна команда займає комірку, довга програма не влазить). «Лічильник команд і стрибок назад» показує, *як* процесор виконує цикл: слова «повтори» в нього немає, є лише стрибок. Обидві ідеї продовжують слайди «Команда — це число» і «Конвеєр команд» з уроку 2. Теорія не суха: інтерактиви з ефектом «вау», як «Хто швидший?» в уроці 2.
- **Гра:** блок-дужка «🔁 ×N» з командами всередині, код `повтори(3) { … }` / EN `repeat(3) { … }`. На перших рівнях один цикл, в останньому наборі й бонусах — цикл у циклі.
- **Розминка:** учень заново розв'язує рівень у стилі уроку 2 і бачить, що в програмі дії повторюються.
- **Час (~46 хв):** 3 повторення · 5 розминка · 18 теорія · 17 гра · 3 підсумок; без необов'язкових частин — ~40.
- **Не робимо:** процедури й умови в грі (наступні уроки, лише тизер у «Для допитливих»); нові плитки чи команди руху; зміни уроку 1; зміни поведінки рівнів уроку 2.

## Припущення

1. Стиль, керування, звуки, iPad/Safari, `localStorage` лише для зірок (try/catch), без даних учня — як в уроці 2.
2. Блок циклу займає 1 комірку пам'яті, кожна команда в ньому — теж 1 (як у Lightbot). Зірки рахуються від кількості комірок.
3. Число повторів 2–9, змінюється тапом по «×N».
4. Ліміт пам'яті рівнів уроку 3 менший за найкоротший розв'язок без циклу: без циклу рівень не пройти.
5. ~9 рівнів (3 набори) + 2–3 бонуси. Найкоротшу програму з циклами розв'язувач уроку 2 (BFS по станах) не знаходить, тому в рівнях є поле `solution`, а `check-levels.js` перевіряє його перебором.
6. Розминку «Довгі сходи» робимо новим рівнем у стилі уроку 2 (без циклу): у рівнях 2-xx повторів замало.
7. Процедури й умови — по одному рядку в «Для допитливих» («стрибок із закладкою», «стрибок, *тільки якщо…*»).
8. Рушій розширюємо лише циклом (YAGNI). Програма стає деревом, тож процедури пізніше лягають на неї природно.
9. Числа на слайдах «Мільярд кроків» і «iPad крутиться в циклі» — оцінки (≈ 1 млрд простих операцій за секунду), на слайді й у «Для допитливих» так і написано: «приблизно».

### Цикл у грі

```
┌──────────────────────────────┬──────────────────────────┐
│                              │ ПАМ'ЯТЬ ▮▮▮▮▮▯▯▯  5/8    │
│     ізометричне поле         │ ┌ 🔁 ×3 ─────────── ✕ ┐  │
│       з Бітом                │ │ [↑] [↑] [↷]  ▏+     │  │
│                              │ └──────── коло 2/3 ───┘  │
│                              │ [💡]                     │
│                              │──────────────────────────│
│                              │ 1 повтори(3) {           │
│                              │ 2     вперед()           │
│                              │ 3     вперед()   ◀       │
│                              │ 4     праворуч()         │
│                              │ 5 }                      │
│                              │ 6 увімкнути()       [EN] │
├──────────────────────────────┴──────────────────────────┤
│ [↑][↶][↷][⤴][💡] [🔁 цикл]          │ ▶ Запуск ⏭ Крок ⟲ │
└─────────────────────────────────────────────────────────┘
```

**Редагування (лише дотики; команди додаються в кінець там, де курсор):**
- **🔁** у пульті додає порожній блок «×2», курсор `▏+` переходить усередину; нові команди потрапляють у блок.
- Тап по порожньому місцю під блоком — курсор назовні; тап усередині блока — курсор у блок.
- Тап по «×N»: 2 → 3 → … → 9 → 2.
- Тап по команді — прибрати її; **✕** на блоці — прибрати цикл разом із вмістом; `Backspace` — прибрати останню команду там, де курсор.
- Вкладеність ≤ 2. Якщо рівень дозволяє лише 1 (`nest: 1`), 🔁 всередині блока неактивна.

**Пам'ять:** смужка «ПАМ'ЯТЬ ▮▮▮▯ 5/8» замість сітки клітинок; блок = 1 комірка, команда = 1. Пам'ять заповнена → Біт: «Пам'ять заповнена!». Рівні без `repeat` (урок 2) показують звичайну сітку, як і раніше.

**Виконання:**
- «⏭ Крок» — одна справжня команда; підсвічуються команда в блоці й рядок коду, на рамці блока — «коло 2/3» (у вкладених — на кожній рамці своє).
- На кінці кола рамка блимає стрілкою «⤴ стрибок назад» — той самий стрибок, що на слайді 5.
- Порожній цикл нічого не робить; Біт: «У циклі нічого повторювати».
- Код: `повтори(3) {` … `}` з відступом; EN — `repeat(3) {` … `}`.

**Зірки й підказка:** ⭐/⭐⭐/⭐⭐⭐ за кількістю комірок, як в уроці 2 (`best` = розмір `solution`). Підказка після 2 невдач — початок `solution`, напр. `🔁×4 { вперед() …`.

### Рівні й розминка

**Розминка 3-00 «Довгі сходи»** (команди уроку 2, без 🔁), зигзаг по діагоналі:
```
1 1 . .
. 1 1 .
. . 1 1
. . . 1t
```
Розв'язок — 12 команд: `(вперед, праворуч, вперед, ліворуч) ×2 + вперед, праворуч, вперед, увімкнути`. Після перемоги кнопка «Що повторюється?» шукає в програмі учня шматок, що йде кілька разів поспіль (`findRepeat`), і фарбує однакові шматки одним кольором. Якщо повтору немає (інший шлях) — показуємо еталон. Ті самі сходи, довші й з тісною пам'яттю, повертаються в рівні 3-04 — вже з циклом. Точні карти всіх рівнів визначаються під час реалізації за правилами нижче.

**Набори (`levels-03.js`):**

| Набір | Рівні (ідеї) | Приклад розв'язку |
|---|---|---|
| **Коридори** (3-01…03) | довгий коридор; транзистор через кожні 2 плитки; сходи вгору | `повтори(3){вперед() вперед() увімкнути()}` |
| **Візерунки** (3-04…06) | довгий зигзаг; обійти квадрат навколо вежі; команди до й після циклу | `вперед() повтори(4){вперед() вперед() праворуч()}` |
| **Цикл у циклі** (3-07…09) | квадрат із транзисторами на кутах; сходинки «2 кроки + стрибок» ×3; спіраль | `повтори(4){ повтори(3){вперед()} праворуч() увімкнути() }` |
| **Бонус** (3-b1…) | пам'ять рівно на оптимум | |

**Правила для кожного рівня з `repeat` (перевіряє `check-levels.js`):**
1. `solution` проходить рівень і займає рівно `best` комірок.
2. Пошук найкоротшої програми (глибина ≤ `nest`, N 2–9) не знаходить коротшої за `best`.
3. Без циклу не пройти: найкоротша плоска програма (BFS з уроку 2) довша за ліміт пам'яті.
4. У наборі «Цикл у циклі» на розв'язок з одним рівнем циклів пам'яті не вистачає.
5. Запас пам'яті: «Коридори» — `best + 2`, решта — `best + 1`, бонуси — рівно `best`.

Пошук (`tools/program-search.js`) іде по станах поля: програма — це послідовність елементів, кожен переводить стан у стан, тож однакові стани з не більшим залишком пам'яті відсікаються. Ліміт пам'яті рівнів з циклами — не більше 8, щоб пошук лишався швидким. Відомий підступ: «увімкнути на кожній плитці» (`повтори(N){вперед() увімкнути()}`) — зайві «увімкнути» нешкідливі, тож пошук може знайти такий коротший розв'язок; тоді або приймаємо новий `best`, або міняємо карту.

**Формат рівня:**
```js
BitGame.level("3-07", {
  title: "Квадрат із транзисторами",
  map: [...],
  start: { x: 0, y: 0, dir: "E" },
  commands: ["forward", "left", "right", "jump", "light", "repeat"],
  nest: 2,                       // дозволена вкладеність циклів (1 за замовчуванням)
  solution: [{ repeat: 4, body: [{ repeat: 3, body: ["forward"] }, "right", "light"] }],
  slots: 7, best: 6,
  say: "Цикл у циклі!"
});
```

### Технічна архітектура

```
shared/bit-game/engine.js     + програма-дерево, expand(), size(), findRepeat(); CODE.repeat
shared/bit-game/bit-game.js   + режим «пам'ять» (блок циклу, курсор, ×N, ✕), відступи й { } у коді,
                                «коло 2/3», спалах «⤴ стрибок назад», підказка з solution;
                                у bitgame:win додаємо program (для «Що повторюється?»)
shared/bit-game/levels-03.js  3-00 (розминка) + 9 рівнів + бонуси
lesson-03-loops/              index.html (Deck), teacher-notes.md, потім Урок-3-теорія-для-вчителя.docx
tools/program-search.js       пошук найкоротшої програми з циклами (лише Node, для check-levels)
tools/check-levels.js         правила 1–5
tools/engine.test.js          тести циклів
game/index.html, site/index.html, README   набір і картка уроку 3
```

- **Програма** — масив, елемент якого — рядок-команда або `{ repeat: N, body: [...] }`. Плаский масив рядків з уроку 2 працює як раніше.
- **`expand(program)`** → плаский список кроків `{ cmd, path, laps: [{ lap, of }] }`. З нього працюють `run`, «Крок» і анімація; рядок коду й «коло 2/3» — через `path`.
- **`size(program)`** — кількість комірок; від неї рахуються зірки й ліміт.
- **`findRepeat(program)`** — чиста функція: шматок, що йде ≥ 2 рази поспіль (для розминки).
- **Слайди теорії** — звичайні інтерактиви в `lesson-03-loops/index.html` на `shared/deck/`, як «Конвеєр команд». Слайд «Мільярд кроків» нічого мільярд разів не виконує: числа — формулою, Біт «розмивається» від швидкості.
- На сторінці уроку 3 підключається лише `levels-03.js`, тож `BitGame.levelIds()` (зірки, посвідчення) — лише рівні уроку 3.

**Нефункціональні вимоги:** розгорнута програма — щонайбільше кілька сотень кроків, анімація плавна, як в уроці 2; 1 учень, статичний сайт (GitHub Pages); приватність без змін; підтримує вчитель, правки рушія — в одному місці.
