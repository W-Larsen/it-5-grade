# Spec: урок 2 «Біт у процесорі» + гра «Біт-програміст»

**Дата:** 2026-10-20 · **Статус:** реалізовано в гілці `lesson-02-bit-processor`, чекає перевірки вчителем на справжньому iPad і дозволу на пуш

Перше заняття блоку «Біт усередині комп'ютера». Попередній spec: [курс + урок 1](2026-10-13-course-and-lesson-01-internet.md).

## Розуміння (підтверджено)

- **Що робимо:** заняття 2 — сайт-презентація (як урок 1) + **власна гра-аналог Lightbot українською** (спільний рушій, рівні вбудовані в слайди, окрема сторінка «Всі рівні») + конспект для вчителя.
- **Навіщо:** Lightbot виглядає застарілим і англійською. Курс поєднує теорію про комп'ютер з практикою програмування — на кожному занятті є обидві частини.
- **Для кого:** той самий учень, 10 років, iPad. Урок 1 йому сподобався.
- **Сюжет:** Біт прилетів на iPad і тепер мандрує «містом-мікросхемою» всередині комп'ютера. Учень — перший програміст Біта.
- **Теорія:** що таке алгоритм і програма (точні команди по черзі) + процесор (виконує по одній команді, мільярди за секунду).
- **Гра:** лише послідовність команд. Ізометричне поле з висотами, команди-іконки, синхронна панель коду з підсвіткою поточного рядка.
- **Не робимо зараз:** процедури, цикли, умови (наступні уроки, по одному); пам'ять і файли, мови програмування (пізніше в блоці); екран, ОС (можливо, пізніше); перехід до Scratch (без дедлайну).

## Припущення

1. Стиль, звуки, керування й персонаж Біт — як в уроці 1 (комікс-наліпки; свайп/дотик на iPad; стрілки, `F`, `M` на Mac).
2. Команди: вперед, ліворуч, праворуч, стрибнути, увімкнути. ~9 рівнів + 2–3 бонусних, з лімітом команд на рівень.
3. Рушій не заважає пізніше додати процедури/цикли/умови, але реалізуємо **лише потрібне уроку 2** (YAGNI).
4. Прогрес — лише `localStorage` (try/catch), без акаунтів і аналітики, без даних учня.
5. Продуктивність: поля до ~8×8, один користувач; ціль — плавна анімація в Safari на iPad.
6. Надійність: сайт статичний (GitHub Pages); запасний варіант — локальний файл на Mac.
7. Підтримує вчитель (власник репозиторію); правки рушія — в одному місці.
8. Сторонню гру в кінці уроку додаємо лише після погодження.

### Гра «Біт-програміст»

**Поле.** Ізометричні «кремнієві» блоки (зелено-сині, з доріжками-провідниками); висоти — стопки блоків. Цілі — **транзистори**: тьмяний «0» → після «увімкнути» світиться «1». Усі горять → струм біжить доріжками, іконка «чип ожив», «дзінь».

**Екран (iPad горизонтально):**
```
┌──────────────────────────────┬─────────────────────┐
│                              │ ПРОГРАМА  (5/8)     │
│     ізометричне поле         │ [↑][↑][↷][💡][ ][ ] │
│       з Бітом                │─────────────────────│
│                              │ 1 вперед()          │
│                              │ 2 вперед()   ◀ зараз│
│                              │ 3 праворуч()        │
│                              │ 4 увімкнути()  [EN] │
├──────────────────────────────┴─────────────────────┤
│ [↑ вперед][↶][↷][⤴ стрибок][💡]  │ ▶ Запуск ⏭ Крок ⟲│
└────────────────────────────────────────────────────┘
```

**Керування.** Дотик у пульті — команда в кінець програми; дотик у програмі — прибрати; `Backspace` — прибрати останню. Ліміт клітинок на рівень. «▶ Запуск» — уся програма; «⏭ Крок» — по одній команді (місток до слайда 4); «⟲» — Біт на старт, програма лишається.

**Панель коду.** Синхронна з іконками: `вперед()`, `ліворуч()`, `праворуч()`, `стрибнути()`, `увімкнути()`. Кнопка **EN** → `forward()`, `turn_left()`, `turn_right()`, `jump()`, `switch_on()`. Поточний рядок підсвічується.

**Правила руху:**
- «вперед» — лише на плитку тієї ж висоти;
- «стрибнути» — на 1 вгору або на будь-скільки вниз;
- «увімкнути» — перемикає транзистор під Бітом;
- ⟳ повертає поле на чверть оберту; на початку рівня обирається ракурс, що найменше закриває плитки (`BitGame.bestRotation`);
- неможливий хід — Біт «стукається», трусить головою, коментує («Ой, там стіна!»); програма йде далі;
- з краю поля не падаємо.

**Перемога і зірки.** Пройдено, коли горять усі транзистори. ⭐ пройдено · ⭐⭐ ≤ оптимум + 2 команди · ⭐⭐⭐ = оптимум. Програма скінчилась, а щось не горить — Біт: «Залишився ще 1 транзистор». Після 2 невдалих запусків — кнопка 💡«Підказка» (перші 2 правильні команди).

### Технічна архітектура

```
shared/bit-game/engine.js      чиста логіка: стан поля, виконання команди, перевірка перемоги (без DOM)
shared/bit-game/bit-game.js    вебкомпонент <bit-game>: SVG-ізометрія, пульт, панель коду, анімації, звуки
shared/bit-game/levels-02.js   рівні уроку 2
game/index.html                «Всі рівні»: мапа світів, зірки
lesson-02-processor/           index.html (тіло сторінки), teacher-notes.md
tools/check-levels.js          перевірка рівнів перебором (Node)
```

- **Звичайні `<script>`, не модулі** — урок відкривається і як локальний файл (`file://`).
- **Shadow DOM** — стилі гри не конфліктують зі слайдами; кольори й шрифти — через CSS-змінні сторінки.
- **У слайді:** `<bit-game levels="2-01,2-02,2-03"></bit-game>` — набір рівнів з перемикачем ①②③.

**Формат рівня:**
```js
BitGame.level("2-04", {
  title: "Перший стрибок",
  map: ["1 1 2t",      // цифра — висота, t — транзистор, . — порожньо
        ". . 1"],
  start: { x: 0, y: 0, dir: "E" },
  commands: ["forward", "left", "right", "jump", "light"],
  slots: 6, best: 4,
  say: "Біт не вміє літати, зате вміє стрибати!"
});
```

**Прогрес:** `localStorage["bitgame:v1"]` — зірки по рівнях; спільні для уроку, «Всіх рівнів» і «Посвідчення» (той самий домен). Без сховища — у пам'яті.

**Взаємодія з навігацією слайдів:** свайп по полю гри не гортає слайд (компонент зупиняє подію); стрілки на Mac гортають слайди; гра — дотиком/мишкою.

**Обробка помилок:** невідомий рівень → картка «Рівень не знайдено» замість білого екрана; порожня програма → ▶ неактивна; `localStorage` недоступний → пам'ять.

**Деплой:** `pages.yml` — копіювати `shared/` як є; обгортати `game/index.html` як уроки. На головній (`site/index.html`) — картки уроку 2 і «Всі рівні».

### Тестування

1. `tools/check-levels.js` — розв'язувач (пошук у ширину по станах поля) для кожного рівня: рівень розв'язний, `best` = справжній оптимум. Підказка (перші 2 команди) береться з того самого розв'язувача під час гри, тому окремого поля `hint` у рівні немає.
2. Вбудований браузер у розмірі iPad (1180×820): дотики, масштаб, анімації, конфлікт свайпів.
3. Фінально — вчитель на справжньому iPad у Safari.

## Ризики

| Ризик | Що робимо |
|---|---|
| Ізометрія з висотами — найскладніша частина; рендер «з'їсть» час | Спершу рушій + простий рендер, перевірка на iPad; прикраси — потім |
| Свайп по полю гортає слайд / подвійний дотик масштабує сторінку в Safari | Зупиняти події в компоненті; `touch-action`; перевірка в Safari |
| Рівень нерозв'язний або `best` неправильний | `check-levels.js` перед кожним комітом рівнів |
| Учень проходить рівні швидше, ніж за 15 хв | Бонус-рівні + сторінка «Всі рівні» |
| Учень «застрягає» | Підказка після 2 невдач; «Далі» на слайді працює завжди |
| Зовнішні посилання не працюють / англійською | Перевірити кожне перед публікацією; позначити мову |
| Урок не відкривається | Запасний варіант — локальний файл на Mac (звичайні `<script>`) |
