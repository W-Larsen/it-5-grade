# Урок 2 «Біт у процесорі» + гра «Біт-програміст» — план реалізації

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Зробити заняття 2: сайт-презентацію «Біт у процесорі» з вбудованою власною грою-аналогом Lightbot українською, сторінку «Всі рівні» і конспект для вчителя.

**Architecture:** Чиста логіка гри (`engine.js`, без DOM, тестується в Node) + вебкомпонент `<bit-game>` (SVG-ізометрія, Shadow DOM) у `shared/bit-game/`. Рівні — дані в `levels-02.js`, перевіряються розв'язувачем (BFS). Урок 2 — копія «шасі» уроку 1 (сцена 1200×800, навігація, панель «Для допитливих», звук, штампи) з новими слайдами; гра вставляється тегом `<bit-game>`.

**Tech Stack:** Vanilla HTML/CSS/JS (звичайні `<script>`, не модулі), inline SVG, Web Audio; Node 25 `node:test` для тестів; Python `http.server` для локального перегляду; GitHub Pages.

**Spec:** [`docs/specs/2026-10-20-lesson-02-bit-processor.md`](../specs/2026-10-20-lesson-02-bit-processor.md). Правила проєкту: [`CLAUDE.md`](../../CLAUDE.md).

## Global Constraints

- Увесь текст для учня — українською; англійська лише в режимі коду EN.
- Без фреймворків, збірки й залежностей; без ES-модулів (має працювати з `file://`).
- Зовнішні ресурси — лише Google Fonts (Unbounded, Nunito, JetBrains Mono), як в уроці 1.
- `lesson-*/index.html` і `game/index.html` — **тіло сторінки без `<!doctype>`/`<head>`**; обгортку додає збірка.
- `localStorage` — лише в `try/catch`; без нього все працює в пам'яті. Ключ гри: `bitgame:v1`; ключ уроку: префікс `bit-cpu:`.
- Жодних акаунтів, аналітики, даних учня.
- Цільовий пристрій: iPad Safari горизонтально (перевіряти у вікні 1180×820); Mac: стрілки — слайди, `F` — повний екран, `M` — звук.
- Стиль — «комікс-наліпки» уроку 1: контури `--ink`, жорсткі тіні, CSS-змінні з `lesson-01-internet/index.html`.
- Команди гри (id → uk → en): `forward` → `вперед()` → `forward()`; `left` → `ліворуч()` → `turn_left()`; `right` → `праворуч()` → `turn_right()`; `jump` → `стрибнути()` → `jump()`; `light` → `увімкнути()` → `switch_on()`.
- Ліміт програми на рівні: `slots` ≤ 12.
- Зірки: 3 — довжина програми ≤ `best`; 2 — ≤ `best + 2`; 1 — інакше (лише за перемогу).

### Task 1: Рушій — рівні й виконання команд

**Files:**
- Create: `shared/bit-game/engine.js`
- Test: `tools/engine.test.js`

**Interfaces — Produces** (глобальний `BitGame`; у Node — `module.exports = BitGame`):
- `BitGame.level(id: string, def: LevelDef): void` — реєструє (кидає `Error` при невалідному визначенні).
- `BitGame.getLevel(id): Level | null`; `BitGame.levelIds(): string[]` (у порядку реєстрації).
- `BitGame.parseLevel(id, def): Level` — `Level = {id, title, say, w, h, cells: (null | {h: number, t: boolean})[][] /* cells[y][x] */, start: {x, y, dir}, commands: string[], slots, best, targets: {x, y}[]}`.
  - `def.map`: масив рядків, токени через пробіл: `"."` — порожньо, `"2"` — висота 2, `"2t"` — висота 2 з транзистором. Висоти 1–4.
  - Помилки: різна довжина рядків, невідомий токен, старт на порожній клітинці, немає жодного транзистора, `slots > 12`, `slots < best`, невідома команда, `dir` не з `N|E|S|W`.
- `BitGame.initialState(level): State` — `State = {x, y, dir, lit: string[] /* відсортовані ключі "x,y" */}`.
- `BitGame.step(level, state, cmd): {state: State, event: Event}` — **не мутує** вхідний стан. `Event`: `"move" | "jump" | "turn" | "on" | "off" | "bump-edge" | "bump-step" | "bump-high" | "no-target"`.
- `BitGame.isWon(level, state): boolean`.
- `BitGame.run(level, program: string[]): {won: boolean, trace: {cmd, event, state}[]}` — зупиняється одразу після кроку, на якому `isWon`.
- `BitGame.stars(level, programLength: number, won: boolean): 0|1|2|3`.
- `BitGame.solve(level): string[] | null` — найкоротша виграшна програма з `level.commands`.
- `BitGame.CODE = {uk: {forward: "вперед()", …}, en: {forward: "forward()", …}}` — значення з Global Constraints.
- `BitGame.remainingText(n): string` — «Залишився ще 1 транзистор» / «Залишилось ще 2 транзистори» / «Залишилось ще 5 транзисторів» (укр. відмінки: 1, 21, 31… → «транзистор»; 2–4, 22–24… → «транзистори»; інакше «транзисторів»; 11–14 → «транзисторів»).

**Правила (з spec):** напрямки на сітці `N: y-1`, `E: x+1`, `S: y+1`, `W: x-1`. `left` — проти годинникової (`N→W→S→E→N`), `right` — за. `forward`: ціль існує і має **ту саму** висоту → `move`; немає клітинки / край → `bump-edge`; інша висота → `bump-step`. `jump`: ціль існує і (`h+1` або нижче) → `jump`; вища за `h+1` → `bump-high`; та сама висота → `bump-step`; немає клітинки → `bump-edge`. `light`: транзистор під Бітом перемикається (`on`/`off`); не транзистор → `no-target`.
