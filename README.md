# IT-курс для 5 класу — дизайн

Додатковий курс IT для одного учня (10 років, 5 клас). Раз на тиждень, 35–45 хв, iPad (+ шкільний ноутбук під кінець).
Без конкретної мови програмування: спочатку «все потроху», потім — те, що учню найцікавіше.

## Розуміння (підтверджено)

- **Що робимо:** (1) план курсу на семестр (~11 занять, жовтень–грудень 2026); (2) інтерактивний сайт-презентацію «Подорож Біта: як працює інтернет» для заняття 1; (3) конспект для вчителя.
- **Для кого:** один учень, 10 років, з програмуванням не стикався.
- **Середовище:** iPad + стабільний інтернет; вчитель також показує з Mac.
- **Логіка курсу:** Lightbot → Code.org / Tynker → Scratch; ~раз на місяць тема «про IT загалом».
- **Не робимо:** конкретну мову програмування, оцінювання, домашні завдання, план на рік.

## Припущення

1. Сторінка українською, сенсорне керування, великі кнопки; мінімум тексту — пояснює вчитель.
2. Один HTML-файл; зберігається в цій теці і публікується приватним посиланням (Artifact).
3. Жодних даних учня: без акаунтів і аналітики; прогрес («штампи») — лише в браузері пристрою.
4. Конспект для вчителя — окремий файл, не на сторінці учня.
5. Перевірку Tynker на iPad поки не робимо.
6. Гру в кінці уроку додаємо лише після окремого погодження з вчителем.

## Журнал рішень

| Рішення | Альтернативи | Чому |
|---|---|---|
| iPad + Safari як основна платформа | Android, ноутбук | Так є в школі |
| Курс на семестр (~11 занять) | Рік; гнучко | Вибір вчителя |
| Заняття 1: 5 хв знайомство + ~30 хв інтернет + 5 хв підсумок | Тільки інтернет; + Lightbot | Знайомство важливе на першому уроці |
| Формат матеріалів: інтерактивний сайт **і** презентація | Лише сайт; лише слайди | Вчитель показує з Mac, учень натискає на iPad |
| **Варіант A:** один HTML, де кожен слайд інтерактивний | B: окремо Slides + сайт; C: сайт-мапа з режимом презентації | Одне джерело, без перемикання вкладок, анімації вбудовані |
| Наскрізна історія «подорож пакета» з персонажем **Біт** | Набір окремих тем | Не нудно для 10-річного, є сюжет і мета |
| Мапа маршруту + «паспорт мандрівника» зі штампами | Без гейміфікації | Видно прогрес, є що «зібрати» |
| Окремий слайд про Wi-Fi | Згадати мимохідь | Запит вчителя; це перше, з чим стикається учень |
| Пріоритет — гарний дизайн, ілюстрації, анімації | «Аби працювало» | Запит вчителя |
| Конспект окремим файлом | На сторінці учня | Сторінка — для учня, текст — для вчителя |
| Гра в кінці — спершу питаємо | Одразу робимо | Запит вчителя |
| «Wi-Fi ≠ інтернет» вбудовано в слайд Wi-Fi (кабель провайдера) | Окремий слайд | Найчастіша дитяча плутанина; не збільшує кількість слайдів |
| ~~Підсумковий слайд-пазл «Інтернет як пошта»~~ — видалено | Залишити | Рішення вчителя; повторення лишається в блоках «Запам'ятай» і квізі |
| Окремий слайд «Біти й байти» після оптоволокна | Пояснити усно | Запит вчителя: показати, що саме летить світлом |
| Пакети одразу після байтів; порядок Байти → Пакети → IP → DNS → Роутери | Пакети в двох місцях (байти + окремий слайд після DNS) | Одна тема — один слайд; кожна станція відповідає на питання, яке ставить попередня |
| Блок «Запам'ятай» на кожній станції (правило або схема) | Лише текст-пояснення | Слайди зрозумілі й без пояснень вчителя |
| Захована теорія: кнопка «Детальніше» → бічна панель «Для допитливих»; на паспорті — «Словничок» | Текст прямо на слайдах | Слайди лишаються легкими, а глибина доступна на запит; панель поза масштабованим слайдом, тому текст читабельний на iPad |
| Не додано: «Чому гра лагає?», «Вежі 4G/5G і хмара» | — | Урок і так ~30–37 хв; можна використати пізніше |

## Дизайн «Подорож Біта»

### Сценарій (~30 хв)

| # | Слайд | Дія учня |
|---|---|---|
| 1 | Що стається за 1 секунду? | Вгадує, скільки пристроїв бере участь (1 / 10 / 100 / 1000) |
| 2 | Мережа — з'єднані пристрої; інтернет = мережа мереж | З'єднує пристрої лініями |
| 3 | Wi-Fi — радіохвилі від роутера; Wi-Fi ≠ інтернет | Відсуває планшет / ставить стіну — сигнал падає; висмикує кабель провайдера — Wi-Fi є, відео немає |
| 4 | Оптоволокно — дані летять світлом (1 = спалах, 0 = темрява) | Відправляє 8 сигналів → отримує байт-літеру |
| 5 | Біти й байти; «Скільки це байтів?» | Пише ім'я → бачить байти кожної літери; вгадує розмір фото / відео / гри |
| 6 | Пакети: байти ріжуть по ~1500, наклейка «номер + адреса» | Складає кадр із пакетів по номерах |
| 7 | IP-адреса — адреса на пакеті | Перевертає картки, підписує «посилку» |
| 8 | DNS — телефонна книга інтернету | Вводить youtube.com → отримує номер |
| 9 | Роутери — сортувальні станції | «Перерізає» кабель — пакети йдуть в обхід |
| 9+ | Бонус на Mac: `ping` / `traceroute` наживо | Дивиться на справжні роутери |
| 10 | Кабелі під океаном | Мапа + цікаві факти |
| 11 | Дата-центр — де «живе» YouTube | Розглядає сервери |
| 12 | Шлях назад — усе за ~0,1 с | Відповідь на слайд 1 |
| 13 | Безпека — 3 правила | Перевертає картки |
| 14 | Міні-квіз | Відповідає на 4 питання |
| 15 | Паспорт мандрівника | Пише ім'я, бачить зібрані штампи |
| — | [Гра — після погодження] | — |

Якщо часу бракує — можна пропустити бонус, Океан і Дата-центр.

### Залученість

- **Біт** 📦 — пакет даних з очима, коментує події короткими репліками.
- **Мапа маршруту** вгорі: 🏠 → 📶 → 🔌 → 🌊 → 🏢, Біт рухається нею.
- **Паспорт мандрівника:** штамп за кожну станцію; наприкінці — заповнений паспорт.
- **Правило «торкнись»:** на кожному слайді хоча б одна дія; текст читається за 10 с.
- **Звуки** (з вимикачем): «вжух», «дзінь», dial-up як пасхалка.
- **Стиль:** яскравий, мультяшний, округлі форми; ілюстрації вбудовані у файл.

### Технічне

- Один HTML, Safari на iPad і будь-який браузер на Mac.
- Mac: стрілки, `F` — повний екран. iPad: свайп і дотик.
- Без зовнішніх даних про учня; localStorage лише для штампів (з try/catch).
